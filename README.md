# Escena invernal
Unity 6.3 LTS (6000.3.26f1), URP.

## Contenido
- Terreno nevado con textura de ambientCG (CC0)
- Coche de policía generado con Tripo AI y optimizado en Blender
- Sirenas rojas y azules rotando con SirenRotation.cs
- Partículas de nieve y humo con texturas generadas proceduralmente
- Bloom, viñeta y niebla
